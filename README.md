One job title, and nothing else: the Official Scapegoat for a Weather Forecasting App. The forecast is wrong often enough that the apology became a full-time position — one salaried human whose whole job is to stand in front of the users and take the blame for the rain nobody predicted. The program assembles the title from the role and the employer, checks it against the gate, and writes it, alone, to the entry file.

## Run it

```sh
node main.ts
```
